# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Polyglot i+1, please report it
privately using GitHub's private vulnerability reporting feature:

https://github.com/ludoviciphilip/Polyglot-AI/security/advisories/new

Please do not open a public issue for security vulnerabilities.

We'll acknowledge your report and work with you on a fix and coordinated
disclosure timeline.

## Scope notes

Polyglot i+1 is a client-side application. Learning data (profile, vocabulary,
history, and an optionally saved Gemini API key) is stored in browser-local
storage and included in exported JSON backups. Please read the "Privacy and
Security" section of the [README](README.md) for details on how the Gemini
API key is handled before reporting related concerns.
